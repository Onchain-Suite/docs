## What Intelligence Covers

The intelligence area helps teams answer questions like:

- Which users are most likely to churn?
- Which wallets show high-value behavior?
- Which cohorts responded to the last campaign?
- Which segments are worth activating next?

## AI assistant

Alongside the editor there's a conversational assistant — ask a question in plain language and it can run curated SQL, surface recommendations, and help shape a segment. It draws on the same read-only schema, so it can never see another workspace's data or modify anything.

Assistant chat costs more AI credits than a one-off SQL generation, because each turn can reason and call tools. See the credit costs on [Generate SQL](/intelligence/generate-sql#modes-and-credit-cost).
